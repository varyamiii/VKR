# Архитектура системы

Система разделена на два серверных компонента.

Backend на FastAPI отвечает за пользовательский интерфейс, работу с PostgreSQL, формирование тестов, наложение шумов и создание PDF-отчётов. Отдельный сервис `tts_service` является HTTP-обёрткой над MeloTTS и выполняет только синтез речи. Такое разделение снижает связность модулей и упрощает сопровождение, поскольку зависимости MeloTTS не смешиваются с основной логикой приложения.

Аудиофайлы и PDF-отчёты хранятся в файловой структуре backend, а в PostgreSQL сохраняются пути к ним. Справочники категорий, фраз, акцентов, шумов и вариантов ответов загружаются заранее через SQL-скрипты. Таблицы тестовых сессий, вопросов и аудиогенераций наполняются в процессе работы приложения.
